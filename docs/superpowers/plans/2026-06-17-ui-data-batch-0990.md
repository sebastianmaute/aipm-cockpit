# UI/Data Batch (v0.99.0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a 16-item UI/data polish batch (pane chrome, Documents/Calendar panes, Next Actions, Dashboard Trends, Reports nav, Influence/Interest, Ask-Claude pill) as v0.99.0.

**Architecture:** Surface-only changes plus one shared data-derivation (Dashboard variance summary reusing the existing pure `computeVariance`). No new persisted `Workspace` fields, no new Turso tables. Engines stay i18n-free; surfaces translate. Each task is file-grouped to be self-contained.

**Tech Stack:** Forked Next.js, React 19, TypeScript, Tailwind (sanctioned AIPM tokens), vitest, playwright/axe.

**Spec:** `docs/superpowers/specs/2026-06-17-ui-data-batch-0990-design.md`

**Repo landmines (apply throughout):**
- Lint is CI `--max-warnings=0`: an unused import/var is FATAL. After removing any JSX usage, remove its import too.
- `react-hooks` purity: no `Date.now()`/`new Date()` in a render body (dashboard already captures time via props/effects); no ref writes in render; sub-components must be module-level.
- `exhaustive-deps` rejects an `obj.member` dep — hoist to a local const first.
- i18n: EN (`i18n.ts`) + DE (`i18n.de.ts`) key sets must be identical (tsc enforces). DE file is CRLF and the Edit tool corrupts umlauts/quotes — **edit DE only via a node UTF-8 write matching `\r\n`**, real umlauts only. `Lang` = `"en-US"|"en-GB"|"de"` (no `"en"`); DE-asserting tests call `loadI18n("de")` in `beforeAll`. Interpolation placeholders are 0-based `{0}`/`{1}`.
- Palette: only sanctioned AIPM tokens — no gradients/shadows/off-palette. palette-sweep only scans CSS, so check new markup by eye.
- axe gate is playwright-only (vitest never runs it). Verify touched views with `npx playwright test e2e/a11y.spec.ts --project=chromium -g "<View>"` before declaring done.

```ts
import { type Lang, t } from "./i18n";
import type { VarianceRow, VarianceKey } from "./snapshot";

export const VARIANCE_LABEL_KEYS: Record<VarianceKey, Parameters<typeof t>[1]> = {
  remainingHours: "trendKpiRemainingHours",
  remainingCost: "trendKpiRemainingCost",
  pctComplete: "trendKpiPctComplete",
  forecastEndDate: "trendKpiForecastSlip",
  spi: "trendKpiSpi",
  cpi: "trendKpiCpi",
};

export function fmtVarianceCell(row: VarianceRow, which: "baseline" | "current"): string {
  if (row.key === "forecastEndDate") return "—";
  const v = row[which];
  if (v === null) return "—";
  if (row.key === "pctComplete") return `${v}%`;
  return String(Math.round(v * 100) / 100);
}

export function fmtVarianceDelta(row: VarianceRow, lang: Lang): string {
  if (row.key === "forecastEndDate") {
    if (row.deltaDays == null) return "—";
    const d = row.deltaDays;
    return d === 0 ? t(lang, "trendsNoSlip") : t(lang, d > 0 ? "trendsSlipDays" : "trendsAheadDays", Math.abs(d));
  }
  if (row.delta === null) return "—";
  const sign = row.delta > 0 ? "+" : "";
  if (row.key === "pctComplete") return `${sign}${row.delta}%`;
  return `${sign}${Math.round(row.delta * 100) / 100}`;
}
```

- [ ] **Step 5: Write the VarianceSummary component**

```tsx
import { type Lang, t } from "./i18n";
import type { VarianceRow } from "./snapshot";
import { VARIANCE_LABEL_KEYS, fmtVarianceDelta } from "./variance-format";

/** Compact baseline-vs-current KPI delta list for the dashboard Trends block.
 *  No snapshot list, no chart — just the variance deltas. Renders nothing when
 *  there is no baseline (empty variance). */
export function VarianceSummary({ variance, lang }: { variance: readonly VarianceRow[]; lang: Lang }) {
  if (variance.length === 0) return null;
  return (
    <dl className="grid grid-cols-2 gap-x-4 gap-y-1 text-sm sm:grid-cols-3">
      {variance.map((row) => (
        <div key={row.key} className="flex items-center justify-between gap-2">
          <dt className="text-muted-foreground">{t(lang, VARIANCE_LABEL_KEYS[row.key])}</dt>
          <dd className="font-medium text-foreground">{fmtVarianceDelta(row, lang)}</dd>
        </div>
      ))}
    </dl>
  );
}
```
