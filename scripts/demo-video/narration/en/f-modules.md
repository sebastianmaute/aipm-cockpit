# Turn functions on or off

## title
A short guide to choosing which functions a project uses.

## opening
Turn functions on or off for each project, so the app shows only what you use.

## f-modules-settings
In Settings, under Functions, you find the list of functions for this project.

## f-modules-switch-on
Switch Time bookings on, and save.

## f-modules-nav
It now appears in the navigation.

## closing
A small project stays simple, and a large one still gets every tool it needs.
