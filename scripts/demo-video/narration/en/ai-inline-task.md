# Ask Claude on a task

## title
A short guide to asking Claude to write or fix one field on a task.

## opening
Ask Claude works on any field of a task. It rewrites what is there, or fills what is empty.

## ai-inline-task-ask
On the task Integrate CRM provisioning, you ask Claude to write the description: what the connector does, and when the task counts as done. Claude shows the change it will make, and you apply it.

## closing
A clear description that says when the work is done saves the questions later.
