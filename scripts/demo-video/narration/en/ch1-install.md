# Install - download and set up the desktop app

## title
Installing AI PM Cockpit takes a few minutes: download the installer from GitHub, run it, and the app opens.

## install-releases
The installer is on the project's GitHub page, under Releases. The newest release is at the top.

## install-download
Under Assets is the setup file for Windows. Click it to download.

## install-keep
The browser warns that the file isn't commonly downloaded. Choose Keep, then Keep anyway.

## install-run
When the download is done, open the file. The setup wizard asks where to install; Install starts it.

## install-progress
Installing takes a minute or two. The progress bar can seem to stand still; that is normal.

## install-finish
Finish starts the app. The first start takes a moment while its background service starts.

## closing
The app is installed. The next chapter connects it and creates the first project.
