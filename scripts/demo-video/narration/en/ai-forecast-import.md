# Import a forecast with Claude

## title
A short guide to importing the team's forecast from a spreadsheet.

## opening
A forecast is the team's estimate of the hours still to come. You import it from a spreadsheet, and Claude works out which column means what.

## tue-follow-plan-off
First, switch off Budget hours follow plan, so the import can set the hours.

## tue-forecast-import
The team's re-plan arrives as a spreadsheet, with notes above the table. Import forecast reads the file, and Ask Claude maps its columns: who, and the hours for each month. You check the preview, then apply.

## closing
With the forecast in the budget, not in a mail attachment, you see early what the rest of the project will cost.
